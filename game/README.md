# 🕹️ Prompt Defender — Browser Mini Game

A retro-futuristic arcade game designed for **Mayank Bajaj's** GitHub profile, styled with **Anthropic Claude's** signature dark charcoal and warm terracotta aesthetic.

## How to Enable 1-Click Play on GitHub Pages

1. In your GitHub repository (`Mayank190405/Mayank190405` or your profile repo):
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Branch**:
   - Select `main` branch.
   - Select `/ (root)` or `/game` as the folder (or use GitHub Pages action).
4. Your game will be live instantly at:
   `https://mayank190405.github.io/game/`

## Features

- **Pure Vanilla Web Stack**: Single self-contained HTML/JS/CSS file.
- **Zero External Dependencies**: Built-in Web Audio API synthesizer for retro arcade sound effects without loading external MP3 files.
- **Responsive**: Full keyboard controls (`Arrow Keys / WASD + Space`) for desktop and custom on-screen touch controls for smartphone visitors.
- **High Score Persistence**: Automatically preserves your best run in browser `localStorage`.
